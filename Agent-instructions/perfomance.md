# Aerix performance notes

Этот файл хранит измерения, чтобы изменения производительности не оценивались
только по ощущениям.

## Baseline до текущего рефакторинга

Измерение выполнено 2026-11-06 на одном экземпляре Quickshell, который работал
около 32 минут:

```text
RSS:           261764 kB
PSS:           181598 kB
Private_Dirty: 152340 kB
Children:      0
```

На момент замера в проекте был один Dock на каждый экран, без отдельных
Quickshell-процессов и без polling Timer для состояния окон или иконок.

## После рефакторинга

Через несколько минут после hot reload того же процесса:

```text
RSS:           258068 kB
PSS:           178024 kB
Private_Dirty: 148796 kB
```

Это не является чистым A/B-тестом: Qt и графический allocator не возвращают
всю освобождённую память после reload. Для честного сравнения нужен полный
перезапуск Quickshell и одинаковый набор открытых окон.

## Что проверять дальше

- RSS и PSS сразу после полного запуска;
- RSS и PSS через 10 минут idle;
- память после 100 циклов наведения на preview;
- память после массового открытия и закрытия окон;
- отсутствие дочерних процессов в idle;
- отсутствие новых QML warnings в `qs log`.

Основные меры текущего рефакторинга: один snapshot Hyprland toplevel'ов,
общий `DockService`, кэш иконок с обновлением только по desktop entries,
ограниченный кэш, lazy snapshot preview и разделённый `DockGroup`.

## Рефакторинг 2026-11-07

Статус hover-раскладки: **исправлено**. Налезание иконок на активный workspace
при движении курсора справа налево больше не воспроизводится.

Повторяющаяся геометрия панели сведена к общей фиксированной ширине и шагу
иконок. Константы читаются из `Metrics` без цепочки свойств-посредников.
Анимация обводки вынесена в `WorkspaceIndicator.qml`.

Группировка окон использует `Map` вместо поиска группы для каждого окна:
O(n + g log g) вместо O(n × g + g log g), где n — окна, g — группы.
Кэш иконок также использует `Map`: проверка размера больше не создаёт массив
ключей. При создании делегата настраивается только новая иконка. Удалены лишний
контейнер группы, визуальный корень сервиса иконок и дублирующее состояние preview.

Проверки:

- 11 468 сравнений старой и новой группировки, ширины панели и hover-расширений;
- 20 проверок компонентов в Quickshell с подключением к Wayland/Hyprland,
  включая обновление кэша и замену делегата без изменения индекса наведения;
- успешная автоматическая перезагрузка рабочей панели, без ошибок в её журнале;
- `git diff --check`; проверка `qmllint` оставляет предупреждения метаданных
  Quickshell (`PanelWindow`, `PopupAnchor`) и обнаружения локальных singleton.
  Создание этих компонентов отдельно проверено в работающем Quickshell.

Замеры того же процесса до и после автоматической перезагрузки:

| Показатель | До | После |
| --- | ---: | ---: |
| RSS, kB | 270684 | 276624 |
| PSS, kB | 191443 | 197371 |
| Private_Dirty, kB | 161088 | 167028 |

После загрузки: дочерних процессов — 0; за двухсекундное измерение в покое
счётчик CPU не изменился. Память выросла примерно на 5,8 MiB; этот замер после
reload не доказывает ни экономию памяти, ни утечку. Снижение RSS/PSS и длительная
стабильность этим рефакторингом не подтверждены — нужен отдельный тест с полным
перезапуском и одинаковой нагрузкой.
