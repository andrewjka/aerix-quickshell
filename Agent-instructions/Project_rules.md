# Правила проекта

- ID Dock (WlrLayershell.namespace) всегда `aerix:dock-panel`, ID верхней статус-панели — `aerix:status-bar`. Сохранять эти значения при дальнейших изменениях.

- Инструкции для агентов, архитектурные решения, замечания и наработки хранить в `Agent-instructions/`. При изменении архитектуры обновлять соответствующий документ в этой папке.

- Описывай комментариями функции, логические блоки и крупные элементы интерфейса, например блок анимации Dock. Очевидные операции пояснять не нужно.
