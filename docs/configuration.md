# Конфигурация темы и анимаций Aerix

- `theme.conf` — выбор файла темы.
- `themes/dark.conf`, `themes/light.conf` — готовые палитры Nord Dark и Catppuccin Latte соответственно, с прозрачностями.
- `motion.conf` — длительности и параметры анимаций.

## Выбор темы

В корневом `theme.conf`:

```ini
theme = "themes/dark"
```

Для светлой темы укажите `theme = "themes/light"`. Расширение `.conf`
необязательно. Относительные пути считаются от корня конфигурации Quickshell;
абсолютные пути также поддерживаются, например `theme = "/home/user/themes/custom.conf"`.
`~` и переменные окружения не раскрываются.

Чтобы добавить тему, скопируйте один из готовых файлов, измените его значения
и укажите путь в `theme.conf`. Коллекций вложенных тем и overrides нет.
Старый `theme.json` больше не используется.

## Формат файла темы

Это ограниченный INI-подобный формат `.conf`: `ключ = значение`, плоский список
цветов и одна секция `[opacity]`. Строки заключаются в двойные кавычки, числа
записываются с точкой без кавычек. Комментарии начинаются с `#` или `;`
вне кавычек; допустимы пустые строки. Escape-последовательности, выражения,
подстановка переменных и вложенные секции не поддерживаются.

Все перечисленные поля обязательны. Неизвестные и повторные ключи,
неверные цвета и прозрачности приводят к отклонению всего файла с сообщением
в журнале. Цвета задаются как `"#RRGGBB"`; alpha регулируется отдельно.

| Цвет | Назначение |
| --- | --- |
| `background` | Фон постоянной верхней панели. |
| `surface` | Фон Dock, popup раскладки и preview. |
| `surfaceElevated` | Заглушка иконки приложения и фон заголовка preview. |
| `text` | Текст и монохромная иконка верхней панели. |
| `surfaceText` | Текст Dock, popup и preview; белый в обеих готовых темах. |
| `hover` | Подсветка наведения и клавиатурного курсора popup. |
| `outline` | Обводка выбранной раскладки, активной группы Dock и preview. |
| `shadow` | Общий цвет внешней тени панелей. |
| `scrim` | Затемнение экрана под полноэкранным overview. |
| `error` | Текст ошибки выбора раскладки. |

Неиспользуемые `accent`, `accentHover`, `activeWorkspace`, `textSecondary`,
`success` и `warning` удалены. Контур активной группы использует `outline`.
Технические цвета прозрачного окна и маски тени заданы в QML.

## Секция opacity

Значения от 0 до 1: 0 — полностью прозрачно, 1 — непрозрачно.

| Поле | Значение готовых тем | Назначение |
| --- | --- | --- |
| `background` | 0.08 | Прозрачность фона верхней панели. |
| `surface` | 0.08 | Фон плавающих поверхностей. |
| `shadow` | 0.48 | Внешняя тень. |
| `hover` | 0.20 | Подсветка наведения/клавиатурного курсора. |
| `outline` | 0.92 | Контур выделения. |
| `scrim` | 0.63 | Прозрачность затемнения экрана под overview. |
| `previewTitle` | 0.88 | Фон заголовка preview из цвета `surfaceElevated`. |
| `textEnabled` | 0.90 | Доступный переключатель раскладки на верхней панели. |
| `textDisabled` | 0.50 | Недоступный переключатель раскладки на верхней панели. |

Обычный текст, текст стеклянных поверхностей, ошибки и заглушка иконки
используют непрозрачный цвет. Анимационная opacity всей поверхности действует
дополнительно при появлении и скрытии.

## Применение изменений

`Theme.qml` наблюдает за `theme.conf` и выбранным файлом через FileView,
без polling и таймеров. Корректные изменения применяются автоматически;
при смене пути наблюдение переключается на новый файл.
При повреждении или недоступности файла сохраняется последняя корректная
палитра. До первой успешной загрузки используется встроенная аварийная
тёмная палитра. Для диагностики доступны `Theme.selectedThemePath`
(запрошенный путь) и `Theme.activeThemePath` (успешно загруженный абсолютный путь).

## `motion.conf`

Файл использует тот же ограниченный INI-подобный синтаксис: `ключ = значение`,
без секций и overrides. Разрешены пустые строки и комментарии, начинающиеся с
`#` или `;`. Все поля обязательны; неизвестный, повторённый или неверный ключ
отклоняет весь файл, сохраняя последний корректный профиль.

| Поле | Формат | Назначение |
| --- | --- | --- |
| `standardDurationMs` | целое число ≥ 0 | Обычный переход, в миллисекундах. |
| `extendedDurationMs` | целое число ≥ 0 | Удлинённый переход, в миллисекундах. |
| `surfaceSpringStartScale` | число от 0 до 1 | Масштаб Dock или popup в первом кадре spring-анимации. |
| `surfaceSpringOvershoot` | число от 0 до 1 | Дополнительный пролёт spring-анимации; `0` отключает его. |
| `dockCloseDelayMs` | целое число ≥ 0 | Задержка закрытия Dock после ухода указателя. |
| `standardBezierCurve` | шесть чисел через запятую | Qt `BezierSpline`: `x1, y1, x2, y2, конечная x, конечная y`. |

Пример:

```ini
surfaceSpringOvershoot = 0.22
dockCloseDelayMs = 800
```

`Motion.qml` наблюдает за файлом через FileView, без polling и таймеров.
До первой успешной загрузки и при ошибке используется последний рабочий профиль.
