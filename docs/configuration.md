# Конфигурация темы и анимаций Aerix

- `theme.conf` — выбор файла темы.
- `themes/dark.conf`, `themes/light.conf` — готовые палитры с цветами и общими прозрачностями.
- `motion.conf` — длительности и параметры анимаций.

## Выбор темы

В корневом `theme.conf`:

```ini
theme = "themes/dark"
```

Для светлой темы укажите `theme = "themes/light"`. Расширение `.conf`
необязательно. Относительные пути считаются от корня конфигурации Quickshell;
абсолютные пути также поддерживаются, например `theme = "/home/user/themes/custom.conf"`.
`~` и переменные окружения не раскрываются.

`theme` — единственный параметр этого файла. Он выбирает файл палитры;
относительный путь разрешается от корня конфигурации. Изменение `theme.conf`
переключает тему без перезапуска оболочки.

Чтобы добавить тему, скопируйте один из готовых файлов, измените его значения
и укажите путь в `theme.conf`. Коллекций вложенных тем и overrides нет.
Старый `theme.json` больше не используется.

## Формат файла темы

Это ограниченный INI-подобный формат `.conf`: `ключ = значение`, плоский список
цветов и одна секция `[opacity]`. Строки заключаются в двойные кавычки, числа
записываются с точкой без кавычек. Комментарии начинаются с `#` или `;`
вне кавычек; допустимы пустые строки. Escape-последовательности, выражения,
подстановка переменных и вложенные секции не поддерживаются.

Все перечисленные поля обязательны. Неизвестные и повторные ключи,
неверные цвета и прозрачности приводят к отклонению всего файла с сообщением
в журнале. Цвета задаются как `"#RRGGBB"`; alpha регулируется отдельно.

| Цвет | Назначение | Где используется |
| --- | --- | --- |
| `background` | Общий полупрозрачный фон интерфейса. Без alpha служит подложкой рабочего стола и превью workspace. | Status bar, Dock, popup раскладки, preview окна и карточки overview; также заглушка иконки Dock. |
| `foreground` | Основной текст и монохромные иконки. | Часы, текущая раскладка, строки popup, подпись пустого Dock, заголовок preview и подписи overview. |
| `accent` | Сообщение, требующее внимания. | Сейчас используется текстом ошибки раскладки. Других потребителей нет. |
| `hover` | Промежуточное выделение без подтверждения выбора. | Используется в popup раскладки: при наведении указателя на строку и при навигации клавиатурой до подтверждения. Сейчас других потребителей нет. |
| `border` | Единый цвет всех рамок. | Контуры выбранной раскладки, активного workspace, hover окна, карточки overview и drag-копии; также постоянный контур preview и граница keyboard cursor. |
| `shadow` | Цвет внешней тени. | Тень Dock и Status bar. Других потребителей нет. |
| `overlay` | Затемнение поверх содержимого. | Полноэкранная подложка overview и временный слой обновления preview workspace. |

Это полный набор цветовых ролей темы. Технические цвета прозрачного окна и
маски тени заданы в QML.

## Секция opacity

Значения от 0 до 1: 0 — полностью прозрачно, 1 — непрозрачно.

| Поле | Значение готовых тем | Назначение и применение |
| --- | --- | --- |
| `background` | 0.78 / 0.84 | Alpha общей поверхности всех панелей (dark / light). Не влияет на непрозрачную подложку workspace. |
| `foreground` | 0.94 | Alpha часов, подписей, иконок и обычного текста. |
| `accent` | 0.96 | Alpha текста ошибки раскладки. |
| `hover` | 0.22 | Alpha двух состояний строки popup: pointer hover и keyboard navigation. |
| `border` | 0.78 | Alpha всех рамок: постоянных, выбранных и hover-контуров. Исключение — рамка активного workspace в Dock использует тот же цвет с alpha `1`. |
| `shadow` | 0.52 | Alpha теней Dock и Status bar. |
| `overlay` | 0.66 / 0.22 | Alpha подложки overview и маски обновления preview (dark / light). |
| `disabled` | 0.52 | Alpha `foreground` в недоступном состоянии. Сейчас применяется к виджету раскладки, когда переключение невозможно. |

Каждая opacity привязана к одноимённой цветовой роли; `disabled` применяется
к `foreground`. `overlay` остаётся цветом затемняющего слоя и не используется
для текста. Анимационная opacity поверхности действует дополнительно при
появлении и скрытии.

## Применение изменений

Корректные изменения применяются автоматически; при смене `theme` наблюдение
переключается на новый файл. При повреждении или недоступности файла сохраняется
последняя корректная палитра. До первой успешной загрузки используется
встроенная аварийная тёмная палитра.

## `motion.conf`

Файл использует тот же ограниченный INI-подобный синтаксис: `ключ = значение`,
без секций и overrides. Разрешены пустые строки и комментарии, начинающиеся с
`#` или `;`. Все поля обязательны; неизвестный, повторённый или неверный ключ
отклоняет весь файл, сохраняя последний корректный профиль.

| Поле | Формат | Назначение и фактическое применение |
| --- | --- | --- |
| `durationMs` | целое число ≥ 0 | Единая длительность всех обычных и spring-переходов. Её используют анимации Dock и его иконок, popup раскладки, preview окна, индикатор workspace и overview. |
| `springStartScale` | число от 0 до 1 | Начальный масштаб любого spring-появления. Используется Dock, popup раскладки и overview при открытии или закрытии. |
| `springOvershoot` | число от 0 до 1 | Дополнительный пролёт spring-кривой; `0` отключает его. Влияет на те же появления Dock, popup раскладки и overview. |
| `dockCloseDelayMs` | целое число ≥ 0 | Задержка закрытия Dock после ухода указателя. Используется только Dock; это намеренно специфичный параметр. |
| `bezierCurve` | шесть чисел через запятую | Общая кривая: `x1, y1, x2, y2, конечная x, конечная y`. Определяет движение Dock, иконок, popup, preview и overview; spring строит её производную с учётом `springOvershoot`. |

Пример:

```ini
springOvershoot = 0.22
dockCloseDelayMs = 800
```

Изменения применяются автоматически. До первой успешной загрузки и при ошибке
используется последний рабочий профиль.
