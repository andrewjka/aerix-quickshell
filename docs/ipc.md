# IPC Aerix

Aerix предоставляет действия оболочки через встроенный `IpcHandler` Quickshell.
Команды локальны для запущенного экземпляра Quickshell: отдельный демон и
пользовательский сокет не используются.

## Overview рабочих пространств

```fish
quickshell ipc call aerix.shell toggleWorkspaceOverview
```

`toggleWorkspaceOverview` не принимает аргументов и ничего не возвращает.
Каждый вызов переключает overview: закрытый открывается на сфокусированном
экране, открытый закрывается. Поведение совпадает с настроенной глобальной
горячей клавишей.

Если вызывающая программа не может однозначно выбрать экземпляр Aerix, укажите
путь к его конфигурации:

```fish
quickshell ipc --path ~/.config/quickshell call aerix.shell toggleWorkspaceOverview
```

Список команд активного экземпляра выводится так:

```fish
quickshell ipc show
```

`aerix.shell` и имена публичных функций — часть внешнего API. Новые команды
будут добавляться туда без предоставления IPC прямого доступа к состоянию
виджетов.
