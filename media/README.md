# Медиа Aerix

Эта папка хранит ресурсы, которые могут использовать несколько частей оболочки.
Общие SVG находятся в `media/icons/`: например, питание, громкость, яркость и
иконки будущих Quick Settings или OSD. Рисунок, принадлежащий только одному
компоненту и не предполагаемый для повторного использования, можно хранить рядом
с этим компонентом.

Добавляя SVG, используйте имя по назначению в нижнем регистре (`power.svg`,
`volume-muted.svg`), а не по названию исходной темы. У файла должен быть
корректный `viewBox`; исходная сетка и пропорции должны оставаться целыми.
Не полагайтесь на `currentColor`: перед использованием проверить, как конкретный
SVG рендерится через Qt, и при необходимости задавать цвет явным способом.

Для каждого добавленного ресурса фиксируйте источник, автора и лицензию в
сопроводительной документации или комментарии SVG. В QML обращаться к ресурсам
относительным URL через `Qt.resolvedUrl`, без абсолютных путей к домашнему
каталогу.
