# Правила проекта

- ID приложения (WlrLayershell.namespace) всегда `aerix:dock-panel`. Сохранять это значение при дальнейших изменениях.

- Оставляй комментарии, не стеснйся, очевидные вещи пояснять не нукжно. Но логические блоки, функции описывай; Отдельные описывай элементы большие: допустим откуда начинается элемент отвечающий за анимацию dock-panel
